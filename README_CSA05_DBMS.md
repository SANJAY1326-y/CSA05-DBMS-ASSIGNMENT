# CSA05 - DBMS Lab Assignment

## SQL Queries for 23 Experiments

This repository contains the SQL practice queries for the **CSA05 Database Management Systems Lab**.

### Contents

- `CSA05_DBMS_All_23_Experiments_MySQL.sql` — SQL queries and supporting table setup/sample data for the lab experiments.

### Requirements

- MySQL 8.0 or later
- MySQL Workbench or MySQL command-line client

### How to Run

1. Open MySQL Workbench and connect to your MySQL server.
2. Open `CSA05_DBMS_All_23_Experiments_MySQL.sql`.
3. Execute the script section by section, following the experiment order.
4. View the results in the **Result Grid** after running each `SELECT` query.
5. For stored procedures and functions, retain the `DELIMITER` statements and execute the complete routine block.

### Notes

- The script uses the `CSA05_LAB` database.
- Sample records are included where demonstration data is needed.
- Experiment 23 uses SQLite/Python as specified in its section; it is not a MySQL experiment.
- Run each experiment separately if your lab system reports an error when executing the entire file at once.
